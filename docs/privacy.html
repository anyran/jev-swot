Jev SWOT（Jev 做题家）隐私政策

最后更新：2026 年 9 月 22 日

Jev SWOT（Jev 做题家）只在用户通过快捷键、扩展按钮或 Alt + 双击主动触发时处理当前题目，不出售数据、不投放广告，也不自动勾选或提交网页答案。

处理的数据

  • 扩展优先在设备内读取当前题目容器的可见 DOM 文本。
  • DOM 不完整时，扩展截取用户选择的题目区域。本地 PP-OCRv5 在设备上处理截图且不上传。
  • 只有用户配置并实际启用视觉模型时，题目截图才会发送至该用户配置的 API；默认每次上传前询问。
  • 如果配置了普通文本模型，OCR 文字和位置可能发送给该模型用于严格 JSON 结构化；模型会单独标出答案、解析、得分和页面杂讯，排除文字不会进入 JEV，也不会发送原始截图。
  • 未配置普通文本模型时，扩展要求用户先人工校正 OCR 题干和选项。
  • TypeSafe Jev 接收经确认的题干、上下文和选项，以返回选项概率。
  • 只有用户点击“答案解析”后，结构化题目及 JEV 概率才会额外发送至用户配置的普通模型。

存储与保留

  • API Key 仅保存在 chrome.storage.session，浏览器重启后清除。
  • 模型地址、模型名、OCR 阈值和禁用站点列表保存在 chrome.storage.local。
  • 扩展不持久保存网页正文、截图、OCR 内容、题目、答案或模型响应。

第三方服务

扩展会按用户操作调用 TypeSafe API，以及用户自行配置的 OpenAI 兼容 API。相应服务的数据处理受其各自政策约束。

控制与联系

用户可以禁用指定站点、清除会话密钥、释放本地 OCR 内存，或卸载扩展。问题可通过 GitHub Issues 提交。
