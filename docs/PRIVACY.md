# JevAnswer 隐私说明

最后更新：2026-09-22

JevAnswer 只在用户通过快捷键、扩展按钮或 `Alt + 双击`主动触发时处理当前题目。

## 处理的数据

- 首选在浏览器内读取题目容器的可见 DOM 文本。
- DOM 不完整时，截取用户选中的题目区域。截图默认先征得本次上传许可；用户选择“仅本地 OCR”时不会上传图片。
- TypeSafe Jev 会收到用户确认后的题干、上下文和选项，用于返回选项概率。
- 用户点击“答案解析”后，所配置的普通模型会收到结构化题目和 JEV 概率。

## 存储

- API Key 仅存于 `chrome.storage.session`，浏览器重启后清除。
- 模型设置、OCR 阈值和禁用站点列表存于 `chrome.storage.local`。
- 扩展不持久保存网页正文、截图、OCR 内容、题目、答案或模型响应。

## 第三方服务

- TypeSafe API：`https://api.typesafe.ai/`
- 用户自行配置的 OpenAI 兼容 API。数据处理规则由相应供应商决定。
- PP-OCRv5 在设备本地运行，不上传图片。

扩展不出售数据、不投放广告，也不自动勾选或提交网页答案。
