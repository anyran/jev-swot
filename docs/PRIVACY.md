# 做题 Jev 隐私说明

最后更新：2026-09-23

做题 Jev 只在用户通过快捷键、扩展按钮或 `Alt + 双击`主动触发时处理网页题目。主快捷键为 `Ctrl/Command + Shift + Y`；若被浏览器或其他扩展占用，可在 `chrome://extensions/shortcuts` 设置备用的 `Windows/Linux: Alt + Shift + Y；macOS: Command + Shift + U`。

## 处理的数据

- `Alt + 双击`会先显示整页逐题面板；用户点击“开始整页分析”后，扩展逐屏扫描主网页及浏览器允许读取的 HTTP/HTTPS 嵌入框架，包括视口外和滚动后才加载的题目，并分别处理每道题。题目文本只在确认后发送；跨域框架文本也遵循此确认。扫描会滚动主页面、框架和内部滚动区，结束或取消后恢复扫描前的位置。浏览器限制或缺少站点访问权限的框架会显示未扫描提示，不会被静默算作已覆盖。
- DOM 可完整读取时，题干和选项按题发送至用户配置的 JEV 或普通模型。主页面 DOM 不完整时，扩展在本地滚动并拼接该题的可见页面截图；只有视觉模型可用且用户逐题允许时才会上传该题截图。框架内视觉题目前不自动截屏，以免把子框架坐标误当作主页面坐标；结果会提示在框架页面单独识别。用户选择“仅本地 OCR”时不会上传图片。Chrome 的 `captureVisibleTab` 要求 `<all_urls>` 或当前标签页的 `activeTab` 权限；本扩展不请求 `<all_urls>`，而是在用户点击扩展图标或触发已注册的浏览器快捷键时使用临时 `activeTab` 权限。如果截图首次被浏览器拒绝，结果面板会提示如何授权并重试。单题框选仍可通过框选快捷键触发。
- 如果普通模型支持视觉，截图会先直接交给视觉模型判断可能答案；扩展不会在首次提示中展示整段识别文本，用户点击详情后才再次请求题干、候选项和必要的图形上下文。
- 如果模型不支持视觉，本地 OCR 识别出的文字和文本框位置会先按视觉行分组。配置 JEV 时，普通文本模型返回题干、选项和排除行证据；扩展依据行证据重建边界，并将题号、答案、解析、得分、对错标记和页面杂讯列为排除文本，不会把这些片段交给 JEV。证据缺失或冲突时会停在校正界面；这不会上传原始截图。
- 如果没有配置 JEV，OCR 原文会整体发送给普通模型直接判断可能答案；用户点击详情后，扩展才请求题干/候选项分离。若普通模型也未配置，则保留本地 OCR 结果并要求人工校正。
- 用户配置的 JEV 决策 API（默认 TypeSafe，也可配置 OpenRouter 等兼容服务）会收到用户确认后的题干、上下文和选项，用于返回选项概率。首次使用自定义 API 域名时，设置页会在保存或测试连接时单独申请该域名的网络权限；拒绝权限后不会向该域名发送请求。
- 结构化题目上点击“普通模型答题”时，普通模型会收到已确认的题干、上下文和选项，并返回答案、教学解释、知识点和不确定性；未配置 JEV 的 OCR 题则先发送原始 OCR 文字。视觉直答只在用户允许时上传截图，详情识别复用本次临时截图；这些模式都不自动提交网页答案。结果详情通过紧凑的图标按钮按需打开，不在页面上持续显示大块弹窗。
- OCR 结构化阶段会将 OCR 文字和文本框位置发送给普通模型（如已配置）；用户点击“答案解析”后，所配置的普通模型才会额外收到结构化题目和 JEV 概率。
- HTTP/HTTPS 网页访问是可选权限；用户可在设置页显式启用它以让 `Alt + 双击`整页扫描在已打开网页中持续可用。整页视觉题截图还需由扩展图标或已注册的浏览器快捷键授予当前标签页临时 `activeTab`；未启用网页访问时，扩展按钮和框选快捷键仍通过用户主动触发的临时权限工作。

## 存储

- JEV 与普通模型的地址、模型名、能力设置和 API Key 存于本机 `chrome.storage.local`，浏览器重启后仍会恢复；扩展不会将这些密钥同步到云端。设置页的“清除本次会话”只清除当前会话缓存；用户点击“清除 API Key”后，才会删除会话和本机保存的密钥。
- OCR 阈值、WebGPU 开关、视觉上传确认和禁用站点列表也存于 `chrome.storage.local`。
- 扩展不持久保存网页正文、截图、OCR 内容、题目、答案或模型响应。

## 第三方服务

- 用户配置的 JEV 决策 API，例如 TypeSafe `https://api.typesafe.ai/` 或 OpenRouter `https://openrouter.ai/`。
- 用户自行配置的 OpenAI 兼容 API。数据处理规则由相应供应商决定。
- PP-OCRv5 在设备本地运行，不上传图片。

扩展不出售数据、不投放广告，也不自动勾选或提交网页答案。
