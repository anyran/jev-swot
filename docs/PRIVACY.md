# Jev SWOT（Jev 做题家）隐私说明

最后更新：2026-09-22

Jev SWOT（Jev 做题家）只在用户通过快捷键、扩展按钮或 `Alt + 双击`主动触发时处理当前题目。主快捷键为 `Ctrl/Command + Shift + Y`；若被浏览器或其他扩展占用，可在 `chrome://extensions/shortcuts` 设置备用的 `Windows/Linux: Alt + Shift + Y；macOS: Command + Shift + U`。

## 处理的数据

- 首选在浏览器内读取题目容器的可见 DOM 文本。
- DOM 不完整时，用户需要使用框选快捷键授予当前页面临时截图权限，扩展再截取框选区域；`Alt + 双击`仅处理能够从 DOM 完整读取的题目，不会绕过该截图权限。只有视觉模型可用且用户允许时才会上传截图；用户选择“仅本地 OCR”时不会上传图片。
- 本地 OCR 识别出的文字和文本框位置会先按视觉行分组，可能发送给用户配置的普通文本模型，用于返回题干、选项和排除行证据；扩展依据行证据重建边界，并将题号、答案、解析、得分、对错标记和页面杂讯列为排除文本，不会把这些片段交给 JEV。证据缺失或冲突时会停在校正界面；这不会上传原始截图。
- 如果未配置普通文本模型，扩展只保留本地规则拆分，并要求用户在调用 JEV 前人工确认题干和选项。
- TypeSafe Jev 会收到用户确认后的题干、上下文和选项，用于返回选项概率。
- 如果用户在结果详情中主动点击“普通模型答题”（或在 JEV 缺少密钥时进入该路径），普通模型会收到已确认的题干、上下文和选项，并返回答案、教学解释、知识点和不确定性；该模式不上传截图。结果详情通过紧凑的图标按钮按需打开，不在页面上持续显示大块弹窗。
- OCR 结构化阶段会将 OCR 文字和文本框位置发送给普通模型（如已配置）；用户点击“答案解析”后，所配置的普通模型才会额外收到结构化题目和 JEV 概率。
- HTTP/HTTPS 网页访问是可选权限；用户可在设置页显式启用它以让 `Alt + 双击` 在已打开网页中持续可用。未启用时，扩展按钮和框选快捷键仍通过用户主动触发的临时权限工作。

## 存储

- 模型地址、模型名、能力设置、TypeSafe API Key 和普通模型 API Key 存于本机 `chrome.storage.local`，浏览器重启后仍会恢复；扩展不会将这些密钥同步到云端。设置页的“清除本次会话”只清除当前会话缓存；用户点击“清除 API Key”后，才会删除会话和本机保存的密钥。
- OCR 阈值、WebGPU 开关、视觉上传确认和禁用站点列表也存于 `chrome.storage.local`。
- 扩展不持久保存网页正文、截图、OCR 内容、题目、答案或模型响应。

## 第三方服务

- TypeSafe API：`https://api.typesafe.ai/`
- 用户自行配置的 OpenAI 兼容 API。数据处理规则由相应供应商决定。
- PP-OCRv5 在设备本地运行，不上传图片。

扩展不出售数据、不投放广告，也不自动勾选或提交网页答案。
