# Chrome Web Store 上架资料（简体中文）

## 名称

Jev 做题家（Jev SWOT）

## 简短说明

识别网页选择题，显示 JEV 选项概率，并按需提供学习解析。

## 详细说明

Jev 做题家（英文名：Jev SWOT）是一款面向自主学习的网页题目辅助工具。

- 使用 `Ctrl/Command + Shift + Y` 框选题目，或用 `Alt + 双击`识别当前题目容器。
- DOM 完整题目可由 `Alt + 双击`直接识别；依赖截图的题目必须使用框选快捷键，以授予浏览器临时截图权限。
- 优先读取网页 DOM；图片文字题可在浏览器本地使用 PP-OCRv5 识别。
- 配置普通文本模型时，OCR 文字和位置会先交给该模型结构化，主动排除答案、解析、得分等页面结果文字；原始截图仍只在用户允许视觉模型时上传。
- 单选题显示总和为 100% 的选项概率；多选题显示每项“应选择”的独立概率。
- OCR 结构化会在需要时调用用户配置的普通模型；只有点击“答案解析”后，才会额外请求教学解析内容。
- 用户确认题目结构后，可以在结果详情中选择“普通模型答题”，获得答案、知识点和不确定性说明；即使没有 TypeSafe Key 也可以从密钥提示进入该路径，该模式不上传截图。
- 结果默认以小型答案提示显示，点击后查看概率和详细解析；支持校正识别结果、查看 OCR 原图/文本框及置信度。
- 设置页可维护敏感站点禁用列表，并控制视觉模型上传截图前是否逐次确认。
- 不自动选择或提交答案，不提供监考规避功能。

用户需要自行提供 TypeSafe API Key；视觉识别和答案解析需要用户自行配置兼容 API。模型配置和 API Key 保存在本机浏览器配置中，不会同步到云端；用户可在设置页主动清除。

## 类别与语言

- 建议类别：教育
- 主要语言：简体中文
- 兼容环境：Chrome/Chromium 109 及以上

## 权限说明

- `activeTab`：仅在用户点击扩展或使用快捷键后截取当前可见选区。
- `scripting`：在用户主动触发后支持当前标签页的交互式题目识别。
- `commands`：注册框选题目的键盘快捷键。
- `offscreen`：在不阻塞网页的离屏文档中运行 Canvas 和本地 PP-OCRv5。
- `storage`：保存模型配置、个性化设置和本机 API Key；页面正文、截图和答案历史不会持久化。
- `https://api.typesafe.ai/*`：把确认后的结构化题目发送给 JEV 概率模型。
- 网页访问：读取当前题目 DOM，并显示隔离的 Shadow DOM 覆盖层；不会修改或提交答案。
- 可选主机权限：仅在用户保存自定义兼容 API 地址时，为该地址单独申请网络权限。

## 单一用途说明

Jev 做题家（Jev SWOT）的单一用途是辅助用户理解网页中的单选、多选和判断题：识别题目、展示选项概率，并在用户请求时生成学习解析。
