# Chrome Web Store 上架资料（简体中文）

## 名称

做题 Jev

## 简短说明

识别网页选择题，显示 JEV 选项概率，并按需提供学习解析。

## 详细说明

做题 Jev 是一款面向自主学习的网页题目辅助工具。

- 使用 `Ctrl/Command + Shift + Y` 框选题目；若该组合冲突，可在 `chrome://extensions/shortcuts` 设置备用的 `Windows/Linux: Alt + Shift + Y；macOS: Command + Shift + U`，或用 `Alt + 双击`扫描整个网页并逐题显示结果。
- 整页扫描覆盖视口外、滚动后加载及浏览器可读取的嵌入框架题目，并逐题显示结果；DOM 不完整时，扩展仅为主网页题目在本地逐屏拼接截图，只有用户逐题允许后才上传给视觉模型。框架视觉题会明确提示，不会使用错位截图。若 Chrome 拒绝截图，可先点击扩展图标或使用已注册的浏览器快捷键授予当前页临时权限，再重试该题。
- 优先读取网页 DOM；需要截图时，支持视觉的普通模型会先直接判断可能答案，点击详情后才识别题干、候选项和图形上下文。
- 不支持视觉时，图片文字在浏览器本地使用 PP-OCRv5 识别。配置 JEV 时，OCR 文字和位置会先按视觉行分组，再交给普通模型返回题干/选项/排除行证据；扩展依据行证据重建边界并主动排除答案、解析、得分等页面结果文字。未配置 JEV 时则将 OCR 原文整体交给普通模型判断，点击详情后再做题干/候选项分离；原始截图仍只在用户允许视觉模型时上传。
- 单选题显示总和为 100% 的选项概率；多选题显示每项“应选择”的独立概率。
- OCR 结构化会在需要时调用用户配置的普通模型；只有点击“答案解析”后，才会额外请求教学解析内容。
- 视觉直答、未配置 JEV 的 OCR 直答和结构化题目的普通模型答题都会返回可能答案、教学解析、知识点和不确定性说明；详情图标按需展示题干与候选项分离结果。
- 结果默认以透明、低存在感的小型答案提示显示，会根据附近页面背景自动调整文字深浅；点击后查看概率和详细解析，悬停时会增强可读性。支持校正识别结果、查看 OCR 原图/文本框及置信度。
- 设置页可维护敏感站点禁用列表，并控制视觉模型上传截图前是否逐次确认。
- 设置页可单独清除当前会话缓存，或彻底清除本机保存的 API Key。
- 不自动选择或提交答案，不提供监考规避功能。

用户需要自行提供 JEV 决策 API Key（默认使用 TypeSafe，也可配置 OpenRouter 等兼容服务）；视觉识别和答案解析需要用户自行配置兼容 API。模型配置和 API Key 保存在本机浏览器配置中，不会同步到云端；用户可在设置页主动清除。

## 类别与语言

- 建议类别：教育
- 主要语言：简体中文
- 兼容环境：Chrome/Chromium 109 及以上

## 权限说明

- `activeTab`：仅在用户点击扩展或使用已注册的浏览器快捷键后，临时截取当前标签页可见区域，用于本地拼接整道视觉题的截图。
- `scripting`：在用户主动触发后支持当前标签页的交互式题目识别。
- `commands`：注册框选题目的键盘快捷键。
- `offscreen`：在不阻塞网页的离屏文档中运行 Canvas 和本地 PP-OCRv5。
- `storage`：保存模型配置、个性化设置和本机 API Key；页面正文、截图和答案历史不会持久化。
- TypeSafe JEV API 使用内置主机权限；OpenRouter 等自定义 JEV/普通模型地址会在用户保存配置时单独申请对应的网络权限。
- 网页访问：读取主页面及可访问嵌入框架中的题目 DOM，并显示隔离的 Shadow DOM 覆盖层；不会修改或提交答案。HTTP/HTTPS 网页访问默认是可选权限，用户可在设置页显式开启以使用 Alt + 双击整页扫描。
- 可选主机权限：用户保存自定义兼容 API 地址时，为该地址单独申请网络权限；网页访问权限仅用于页面题目识别，不会自动上传页面内容。

## 单一用途说明

做题 Jev 的单一用途是辅助用户理解网页中的单选、多选和判断题：识别题目、展示选项概率，并在用户请求时生成学习解析。
